# Research structure and evidence plan

The prerequisite graph is in docs/01_world_models_eli5.md. The chapter order follows pixels → representations → prediction → interventions → planning → evaluation.

Nine equally important workstreams map to concrete artifacts:

| Workstream | Artifact | Remaining gate |
|---|---|---|
| Conceptual learning | chapters 1–4, glossary | deepen individual concept treatments |
| Mathematics and architectures | chapters 3,5–7 | full primary/code review for later 2026 models |
| Current literature | references, survey | wider citation-chain search |
| Open resources | catalog | complete chosen-asset license/size/schema records |
| Training/fine-tuning/inference | chapter9, adapter | real pretrained weight execution |
| Reproducible PyTorch | src,tests,results,uv.lock | broaden physics and independent test distributions |
| Applications | chapter10 | prospective task-specific validation |
| Original research | chapter11 | falsifying experiments, focused novelty audit |
| Learning roadmap | chapter12 | learner assessment and portfolio execution |

Do not collapse these gates into one claim that all world-model research has been reproduced. The verification report is the authoritative execution record.
